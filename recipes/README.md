# Recipes

One folder per recipe: `<id>/recipe.json` and `<id>/key.asc`. The app builds every folder here into itself, and offers a recipe on the models its CHIDs match. This template carries none; add yours in your fork. [docs/RECIPES.md](../docs/RECIPES.md) describes the files, and [omarchy-surface-pro-11-installer](https://github.com/turbineBMW/omarchy-surface-pro-11-installer/tree/main/recipes) has a working one.
